运行边界
44 个角色沿依赖顺序执行，同一时刻一个角色。每个角色通过真实 Pi Agent 状态机读取工具、调用模型并交付合同产物。格式与证据 ID 自动检查，事实与论证由审阅者把关。
网络检索工具提供 PubMed / Crossref 题录，只在请求成功时记录结果。完整原文和证据卡需导入；不会把题录伪装成全文。绘图角色输出方案或 SVG 源码，网页尚未提供科研绘图渲染器。
项目与日志存储在本机浏览器，建议定期导出备份。关闭标签页、电脑休眠或浏览器后台节流可能中断执行。此版本无需连接 Codex。
