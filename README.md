# ReviewForge V1

**独立于 Codex 的 44 角色科研综述网页工具。**

在线使用：[ReviewForge V1 工作台](https://veritas123-s.github.io/reviewforge-v1/)。本仓库与历史进度快照网站、V2 七角色运行时独立。

## 使用

1. 在“模型连接”输入 API Base URL、API key 与模型调用名，点击测试连接。默认学校服务 `https://models.sjtu.edu.cn/api/v1`，思考模型别名 `deepseek-reasoner`。模型可用性以你账户为准。
2. 新建课题，明确范围、问题和目标。在首次执行前导入 TXT / MD 原文并建立证据卡（原文引句与定位）。
3. 启动可执行角色。每个角色通过真实 Pi Agent core 1.0.2 执行模型—工具—模型循环。串行执行，模型请求间至少 6.5 秒；每角色最多 6 轮、每请求最多等待 20 分钟。
4. 角色产物进入“待审阅”，请核查原文证据与推断层级，填写意见后批准或退回。完成依赖后批准对应质量门，再点击启动继续。失败和中断角色可在“产物与审阅”重试。
5. 下载 44 角色工作报告、项目备份与 Markdown 综述草稿；草稿采用全文编辑或主笔文本，附参考文献和严谨表达修改意见，仍须作者核查。校验经验候选后提升，在后续项目同角色运行中复用；退回角色会撤销相关经验的提升。经验不是模型训练。

进度是“人工审阅通过角色数 / 44”，模型生成完成不等于通过。事件和思考显示来自真实调用；不模拟内部推理。科学质量、原创性、图件质量和期刊接收不能由角色数量或格式检查保证。

## 数据与运行边界

- API key 只在当前页面内存中，刷新后重新输入。没有把 key 写入浏览器存储、备份、源码或日志。请求直接发送到你填写的服务，服务必须支持 OpenAI 兼容响应与浏览器 CORS。
- 课题、文献、证据、产物与事件在当前浏览器 IndexedDB。浏览器清理、隐私模式退出或设备故障会丢失本地数据，请定期备份。不同设备不自动同步。
- 页面保持打开时执行；关闭页面、休眠和后台节流可能中断。重新打开会标记旧运行“已中断”，允许手动重试。**GitHub Pages 提供静态网页，不提供后台常驻执行。** 不依赖 Codex，不承诺关掉浏览器后继续工作。
- 来源 SHA256 与证据引用检查用于阻止错误 ID 和导入损坏。格式通过不代表事实成立。题录不能支持实质科学论断。原文与证据在生成角色产物后锁定；扩大文献范围请新建项目，避免旧产物沿用。
- PubMed/Crossref 工具只提供真实成功请求的题录，不自动导入为全文证据。服务跨域、网络和速率限制会暴露为工具错误。PDF/Word 尚需先提取文本。绘图角色目前交付方案或 SVG 源码，未集成渲染器。
- 不自动批准角色、质量门、经验或最终投稿。G5 仅代表可供作者审阅的最终候选。
- 默认只调用用户模型服务，不会回退到 GPT/Codex。连接测试同样会消耗你选择服务的少量 token。API 未返回用量的请求单列“用量未知”，不把估算当实际计费。

## 开发与自托管

构建要求 Node.js 22.19+（上游 Pi 的 engine 要求）。网页运行无需 Node 或 Python。

```sh
npm ci
npm test
npm run build
# 通过任意静态 HTTP 服务器提供当前目录；不要直接打开 file://
python -m http.server 8080
```

GitHub Pages 部署默认分支根目录即可。已提交浏览器 bundle 与依赖锁定文件，无第三方字体、追踪脚本或 CDN 运行时依赖。UI 使用 textContent 展示模型与来源内容，禁止执行模型生成的 HTML/SVG。同一浏览器的 Web Locks 防止多个标签页覆盖项目或重复执行。

`src/engine.js` 使用上游 Pi Agent 状态机和自定义 OpenAI 兼容 SSE 桥接。Q03/Q06 先在独立实例中只读原始证据形成盲审，再在新实例中对照作者产物，两阶段产物随运行报告保存。`src/state.js` 管理 44 角色依赖、质量门、证据检查和失效传播。`src/app.js` 管理本地项目、密钥、运行控制和事件驱动 UI。合同在 `agents.json`。

测试含实际 Pi 引擎配合显式模拟模型响应的两轮工具调用、S/E 引用隔离、题录证据限制、截断流、状态恢复、依赖与失效传播；模拟测试不代表真实模型科研产出验收。发布时不使用任何个人 API key。
